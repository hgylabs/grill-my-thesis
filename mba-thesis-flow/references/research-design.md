# 研究设计方法菜单

## 方法选择决策树

按顺序自问：

1. **有没有可量化的数据？**
   - 有公司内部/数据库量化数据 → 二手数据回归
   - 能发问卷且能回收 ≥200 份 → 问卷调查实证
   - 只有定性材料（访谈、内部文档、复盘记录）→ 案例研究
2. **研究问题是什么类型？**
   - "现状如何 / 有哪些表现" → 描述性：案例研究、访谈
   - "A 和 B 有没有关系 / A 是否影响 B" → 实证：回归（问卷或二手数据）
   - "机制是什么 / 过程怎么发生" → 案例研究、扎根式访谈
3. **样本与方法匹配硬底线**：
   - 多元回归 n ≥ 30，且每个自变量 5-10 个观测
   - 结构方程 / CFA：n ≥ 200
   - 单案例：≥ 3 个独立信源三角验证；多案例：≥ 4 个案例（2×2 或复制逻辑）

## 四类方法的写法要点

### 问卷调查实证
- 量表**优先成熟量表**并注明出处（作者、年份、原文题项）；自编量表要写编制步骤与预测试
- 问卷结构：甄别题 + 变量题项（Likert 5/7 点）+ 人口统计题
- 发放渠道写清（企业内部发放 / 行业协会 / 问卷平台），预计回收率按 30-50% 估算发放量
- 常见坑：共同方法偏差（程序补救：匿名、分时段；统计补救：Harman 单因素）

### 二手数据回归
- 数据库写明（CSMAR / Wind / 上市公司年报手工整理），样本筛选规则写成可复现的筛选步骤
- 变量：被解释变量、解释变量、控制变量（行业、规模、年限等，注明选取依据）
- 必备：描述统计、基准回归、稳健性（替换变量 / 缩尾 / 固定效应）、内生性讨论（滞后变量 / 工具变量 / 至少文字承认局限）

### 单案例研究
- 案例选择依据写透：为什么这家公司是"典型 / 极端 / 复制"案例
- 证据链：访谈（分层级）、内部文档、公开报道三角验证；列证据表
- 分析方式：编码 → 主题 → 与理论对话，禁止写成公司简介 + 经验总结

### 多案例研究
- 案例间逻辑：复制（逐项复制 / 差别复制）而非随机抽样
- 跨案例比较表：案例 × 主题维度矩阵

## 假设书写规范

- 格式：H1、H2…（主假设）；H1a、H1b…（子假设）
- 每条假设：方向明确（正向 / 负向）、可证伪、理论依据指向第 2 章某小节
- 中介：H1 "X 正向影响 Y"；H2 "M 在 X 与 Y 之间起中介作用"
- 调节：写清调节方向及理论理由

## 理论选择速查（MBA 常用）

| 理论 | 适合解释 |
|---|---|
| 资源基础观（RBV） | 企业为什么有持续优势 |
| 动态能力理论 | 环境变化中企业怎么调整 |
| TOE 框架 | 技术-组织-环境因素对采纳的影响 |
| 计划行为理论（TPB） | 个体行为意愿 |
| 委托代理理论 | 治理、激励、股权问题 |
| 利益相关者理论 | ESG、社会责任 |
| 双元理论（探索/利用） | 创新、组织学习 |
| 制度理论 | 合法性、政策响应 |

注意：理论是解释机制的工具，不是帽子。写清"用它的哪条命题解释你的哪段关系"。
