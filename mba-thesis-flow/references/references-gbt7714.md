# 参考文献规范（GB/T 7714-2015）

## 基本要求

- 数量：30-60 条（按学校要求）
- 结构：中英文都有，英文 ≥ 1/3；主题线 + 理论线 + 方法线覆盖
- 时效：近 3-5 年文献 ≥ 1/3；经典理论文献（如 Barney 1991）不受时效限制
- 排序：顺序编码制（按正文引用先后编号 [1][2]…）或著者-出版年制，**按学校规范二选一，全文统一**

## 常用条目格式（顺序编码制示例）

期刊论文 [J]：
```
[1] 陈晓红, 唐湘博, 张威威. 数字经济绿色发展的全景扫描与理论展望[J]. 管理世界, 2023, 39(2): 1-16.
```

英文期刊 [J]：
```
[2] BARNEY J. Firm resources and sustained competitive advantage[J]. Journal of Management, 1991, 17(1): 99-120.
```

学位论文 [D]：
```
[3] 王明. 数字化转型对企业绩效的影响研究[D]. 上海: 复旦大学, 2022.
```

专著 [M]：
```
[4] 陈晓萍, 徐淑英, 樊景立. 组织与管理研究的实证方法[M]. 3版. 北京: 北京大学出版社, 2018.
```

报告 [R] / 电子文献 [EB/OL]：
```
[5] 中国信息通信研究院. 中国数字经济发展研究报告[R]. 北京: 中国信通院, 2023.
[6] 艾瑞咨询. 2024年中国企业数字化白皮书[EB/OL]. (2024-03-15)[2025-01-10]. https://www.iresearch.com.cn/.
```

格式要点：作者姓前名后大写（英文）；3 位以上作者列前 3 位后加"等 / et al."；期刊用全名不缩写（或按学校要求缩写）。

## 管理研究常用文献源

中文核心：《管理世界》《管理科学学报》《南开管理评论》《中国工业经济》《会计研究》《管理评论》《科研管理》《经济管理》

英文期刊：SMJ、AMJ、AMR、JBR、Journal of Business Ethics、Information & Management、Technovation（按选题领域选）

数据库：CNKI、Web of Science、Scopus、EBSCO（商科全文）、CSMAR/Wind（数据）

## 交付前检查

1. **去重**：同一文献多次出现合并；同名不同文献核对年份
2. **引用-文献对照表**：正文每处 [n] ↔ 文献表条目，双向无遗漏、无正文引了但表里没有、无表里有但正文没引
3. **`[待核验]` 清零**：所有条目在交付前核实到原文；核验不了必须删除
4. 格式统一：标点全半角、期号格式、页码格式逐条一致

## 诚实条款

- agent 不确定真实性的文献一律标 `[待核验]`，绝不静默输出"看起来像真的"条目
- 经典文献的卷期页码凭记忆不可靠，必须让用户核对或标注待核验
