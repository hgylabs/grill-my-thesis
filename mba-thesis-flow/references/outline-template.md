# 五章制大纲模板（MBA 学位论文）

以 3 万字为例给出字数占比；实际按学校要求缩放。MBA 论文默认"应用导向"：问题来自企业真实场景，结论落到可操作的管理建议。

## 结构总览

| 部分 | 字数占比 | 说明 |
|---|---|---|
| 摘要（中英文） | 600-1000 字 | 问题-方法-发现-建议，各一句到位 |
| 第 1 章 绪论 | 10-12% | 背景、问题、意义、思路 |
| 第 2 章 文献综述与理论基础 | 18-22% | 三线式综述 + 理论框架 |
| 第 3 章 研究设计（或案例与现状分析） | 15-20% | 方法、变量、数据、技术路线 |
| 第 4 章 实证分析 / 数据分析 / 案例分析 | 25-30% | **全文最长、最重的章** |
| 第 5 章 结论与建议 | 10-12% | 结论、管理建议、局限与展望 |
| 参考文献 | — | 30-60 条，GB/T 7714 |
| 致谢 | 300-500 字 | |

## 各章小节骨架

### 第 1 章 绪论
1.1 研究背景（行业痛点 → 企业场景 → 问题浮现，三层递进）
1.2 研究问题的提出（从背景收拢到 1-3 个 RQ）
1.3 研究意义（实践意义为主，理论意义一句带过——MBA 论文特征）
1.4 研究思路与论文结构（一段话 + 技术路线图引用）

### 第 2 章 文献综述与理论基础
2.1 核心概念界定（只界定论文用到的概念）
2.2 主题线综述（研究对象相关文献：述 + 评）
2.3 理论线综述（所用理论的来源、发展、在管理研究中的应用）
2.4 方法线综述（同类问题常用方法与数据，简短）
2.5 文献评述与研究缺口（明确 gap statement）
2.6 理论框架构建（框架图 + 变量关系陈述）

### 第 3 章 研究设计
3.1 研究方法选择及理由
3.2 数据来源与样本（问卷结构 / 案例选择依据 / 数据库说明）
3.3 变量定义与测量（表格：变量-题项-量表出处）
3.4 研究假设汇总（实证类；H1、H1a…）
3.5 技术路线（流程图）

### 第 4 章 实证分析（数据分析 / 案例分析）
4.1 描述性统计（样本画像、变量分布）
4.2 信度与效度检验（问卷类）
4.3 相关分析
4.4 假设检验（回归 / 中介调节 / 案例主题分析），每小节对应一个假设或主题
4.5 稳健性检验 / 结果讨论（结果与文献对话：一致？相反？为什么）

### 第 5 章 结论与建议
5.1 研究结论（逐条对应 RQ，不引入新发现）
5.2 管理建议（**每条建议写清：谁、在什么场景、做什么、需要什么资源**；建议必须能在第 4 章结果中找到依据）
5.3 研究局限（数据、方法、外部效度各一条，诚实但有分寸）
5.4 未来展望（1-2 条即可，不堆砌）

## 常见结构病

- 第 4 章比第 2 章还薄 → 头重脚轻，评审必挑
- 第 5 章建议在第 4 章找不到依据 → "两张皮"，最常见毙稿理由
- 概念界定写成教科书摘抄 → 只写你用的
- 每章末尾没有小结句 → 加 2-3 句承上启下
