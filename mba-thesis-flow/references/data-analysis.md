# 数据分析规范

## 总红线

1. **只用真实数据**：一切统计量（样本量、均值、系数、p 值）必须能追溯到用户提供的数据文件
2. **可复现**：报告开头注明数据文件名、软件/工具、处理步骤（缺失值、异常值、变量变换）
3. **如实呈现**：不显著是发现不是失败；禁止为显著性换样本、挑模型、改数据

## 路径一：问卷数据（SPSS / Jamovi / R / Python 均可）

分析顺序固定，前一步不过关不进后一步：

1. **数据清洗**：作答时长过短（如 < 1/3 中位时长）、全部同选、甄别题不通过 → 剔除并报告剔除量
2. **描述统计**：样本人口统计表；变量均值、标准差、偏度峰度
3. **信度**：各量表 Cronbach's α ≥ 0.7（< 0.6 必须处理或删题）
4. **效度**：KMO ≥ 0.7、Bartlett 显著 → EFA（载荷 ≥ 0.5、交叉载荷处理）；用 CFA 时报告组合信度 CR ≥ 0.7、AVE ≥ 0.5
5. **相关分析**：Pearson 矩阵，初步验证方向
6. **假设检验**：
   - 主效应：多元回归（报告 B/β、SE、t、p、R²、F），控制变量先进
   - 中介：Baron & Kenny 逐步法 + Bootstrap（5000 次）置信区间，二者都做
   - 调节：交互项法，中心化处理，画简单斜率图
7. **共同方法偏差**：Harman 单因素检验（首因子 < 40%）

## 路径二：二手数据（Stata / R / Python）

1. 描述统计 + 分组差异初判
2. 基准回归（OLS / 面板：固定效应按 Hausman 定）
3. 稳健性：替换变量测度、连续变量缩尾（1%/99%）、更换样本窗口、改变聚类层级
4. 内生性：解释来源（反向因果 / 遗漏变量 / 测量误差），处理手段（滞后一期 / 工具变量 / Heckman），做不了的至少文字承认并讨论方向
5. 结果表规范：系数下星号（* p<0.1, ** p<0.05, *** p<0.01），括号内 t 值或标准误（注明是哪种）

## 路径三：访谈 / 案例

1. 编码：开放编码（贴标签）→ 主轴编码（归主题）→ 选择编码（核心范畴）；列编码表（原文语句 → 初始概念 → 主题）
2. 三角验证：访谈 × 文档 × 公开资料交叉印证，列证据表
3. 信效度替代：编码者一致性（第二人抽编 20%）、厚描述、模式匹配
4. 禁止虚构访谈引文；引用受访者原话注明编号（如 M3-销售总监）

## 表格规范

- 三线表：顶线、栏目线、底线，无竖线
- 表题在表上方（"表 4-1 描述性统计"），图题在图下方（"图 4-1"）
- 正文必须引用每张表图（"如表 4-1 所示…"），未引用的删

## 结果解读写法

- 先报数字（方向、显著性），再解释含义，最后勾连假设（"H1 得到支持 / 未得到支持"）
- 与文献对话：结果与谁的结论一致、与谁相反、可能的解释
- 未通过验证的假设单独立小节讨论原因，这常是加分项
