# 文献综述写作规范

## 目标

综述不是文献罗列，是**用文献搭出"别人做到哪、我还差哪"的论证**。写完的标准：读者能一句话复述你的研究缺口（gap statement）。

## 三线式结构

1. **主题线**：你的研究对象相关研究（如"数字化转型对绩效的影响"）
2. **理论线**：你用的理论（如资源基础观、动态能力、TOE 框架）——来源、核心命题、在管理研究中的典型应用
3. **方法线**：同类问题用什么数据和方法、样本多大、结论是否一致（简短，一节即可）

三条线收拢到 2.5 节的缺口陈述。

## 综述矩阵（动笔前先填表）

| 作者(年份) | 研究问题 | 理论 | 数据与方法 | 核心发现 | 局限/未回答 |
|---|---|---|---|---|---|
| | | | | | |

矩阵填完，纵向看"局限/未回答"列，缺口自己浮现。矩阵可放正文或附录，至少必须作为你的工作底稿。

## "述 + 评"节奏

每个主题段落的写法：

1. **述**：归纳 2-4 篇代表性文献的共识（"围绕 X，现有研究形成两类观点：A 类认为…（作者, 年份）；B 类发现…（作者, 年份）"）
2. **评**：指出分歧、不足或未覆盖的情形（"但上述研究均基于 … 样本，对 … 情形缺乏讨论"）
3. **勾连**：说明这与你的研究问题什么关系

## 缺口陈述句式

> 综上，现有研究在 [主题] 上已取得 [共识]，但仍有三点不足：一、…；二、…；三、…。本文拟在 [情境/数据/方法] 上对上述缺口作出回应。

缺口与创新点一一对应：开题报告写了几个创新点，综述就必须搭出几个缺口。

## 常见病与处方

| 病 | 症状 | 处方 |
|---|---|---|
| 罗列不复述 | "张三(2020)研究了X。李四(2021)研究了Y。" 逐条流水账 | 一段一个观点，文献作为观点的证据 |
| 以述代评 | 只有归纳没有批评 | 每段末尾强制一句"评" |
| 综述与自己的研究脱节 | 评完不落到缺口 | 缺口陈述必须出现且点名 |
| 只引旧文献 | 近三年文献缺位 | 主题线近三年文献 ≥ 1/3 |
| 只引中文或只引英文 | 文献结构单一 | 中英互补，英文 ≥ 1/3 |
| 引而不读 | 引用内容与原意不符 | 每条引用能翻到原文对应处 |

## 文献真实性

- 每条引用必须有可核验的完整出处；不确定真实性的标 `[待核验]` + 检索式
- 禁止引用你（agent）"记得有"但拿不出处的文献
- 二手转引（从综述里看到的文献）要标注转引或找到原文
