# MBA 开题报告辅导（mba-proposal-coach）

## 定位

把选题卡升级为一份**能过评审**的开题报告。辅导式推进：每一节先给写作要点和骨架，用户确认后成文，绝不一次性甩出整篇——开题报告的价值在论证过程，不在排版。

## 硬门禁（Hard Gates）

1. **输入门禁**：必须有选题卡（`thesis/01-选题卡.md`）或用户已确认的题目、研究问题、数据来源。两者都没有时，停止并引导先运行 `mba-topic-grill`。
2. **文献真实性门禁**：报告中的每一条文献必须有真实的作者、年份、期刊/出处。**不确定真实性的文献一律标注 `[待核验]`** 并附检索式（数据库 + 检索词）。宁可少引，不许编造。发现自己在编造文献时立刻停止并告知用户。
3. **图示门禁**：技术路线必须配图（Mermaid flowchart 或文字版流程描述，视 agent 渲染能力而定）。
4. **闭环门禁**：每个研究问题（RQ）必须能回答三件事——用什么数据、什么方法、预期得到什么结论。答不齐三件的 RQ 必须改写或删除。
5. **倒排门禁**：进度安排以答辩日期为锚点倒排，粒度到周，并预留 ≥4 周缓冲。
6. **答辩门禁**：成文前必须完成"评审十问"模拟（见 Phase 3），暴露的弱点改回报告后才允许交付。跳过十问直接交稿视为未完成。

## 执行流程

### Phase 0：输入确认

- 读取 `thesis/01-选题卡.md`（存在则直接解析；不存在则向用户索要题目、研究问题、数据来源）
- 一次问清 4 个事实项：学位类型（专硕 / 学硕，若选题卡未标注则必问）、学校是否有开题模板（有则索要路径/内容）、字数要求（默认 5000-8000 字）、已读文献量（决定综述写多细）
- **类型分流**：记录学位类型并贯穿全程——专硕开题报告重"实践意义 + 管理启示"，学硕开题报告重"理论缺口 + 学术贡献"。两者措辞、创新点口径、评审十问判据不同，不得混用。

### Phase 1：资料盘点与缺口清单

- 基于选题卡的文献线索，列出"综述三条线"各需补哪些文献（主题线 / 理论线 / 方法线）
- 产出一张**缺口清单**：目前有什么文献、缺什么、去哪个库用什么检索式补（CNKI / Web of Science / Google Scholar）
- 明确告知：本 skill 不伪造文献，缺口由用户检索补齐或明确授权标 `[待核验]`

### Phase 2：七大件逐节辅导

按顺序逐节推进，每节固定节奏：**先给要点清单（3-5 条）→ 用户确认或修改 → 成文**。

1. **选题背景与意义**（约 800-1200 字）
   - 实践背景：行业真实痛点 + 具体企业/场景证据，禁用"随着 XX 的快速发展"式空话开头
   - 理论缺口：现有研究差在哪，两三句话说清
   - **类型分流**：专硕意义须落到"对企业管理者有什么用"（管理启示导向）；学硕意义须落到"对学术文献有什么增量"（理论贡献导向）

2. **国内外文献综述（简版）**（约 1500-2500 字）
   - 三条线组织，每条线"述 + 评"：先归纳共识，再指出分歧与不足
   - 结尾必须落到一句明确的**研究缺口陈述**（gap statement），与创新点一一对应
   - 详细规范见 mba-thesis-flow 的 `references/literature-review.md`（如可用）

3. **研究内容与拟解决的关键问题**
   - 研究内容按 RQ1-RQ3 展开；实证类配假设 H1、H1a…（假设必须可证伪）
   - 每条 RQ 通过闭环门禁（数据-方法-预期结论三件套）

4. **研究方法与技术路线**
   - 方法菜单：问卷调查 / 单案例 / 多案例 / 二手数据回归 / 混合方法；写明选择理由
   - 变量测量：优先成熟量表并注明来源；自编量表必须写编制步骤
   - **技术路线图**：从数据收集到结论的完整流程图

5. **创新点**（2-3 条）
   - 每条创新点必须对应第 2 节的一个研究缺口，格式："针对 [缺口]，本文 [做法]，预期实现 [贡献]"
   - 检验标准：评审拿着这条去搜文献，找不到完全相同的组合
   - **类型分流**：专硕创新点落到"可操作管理启示/情境化应用"；学硕创新点必须落到"理论增量"（新构念/修正关系/拓展边界），纯实务建议不构成学硕创新点

6. **进度安排**
   - 倒排表格：开题 → 数据收集 → 分析 → 初稿 → 修改 → 查重 → 答辩，粒度到周
   - 风险项（数据审批、问卷回收慢）单独标注缓冲

7. **参考文献**（15-40 条）
   - GB/T 7714-2015 格式，中英文文献都有（英文 ≥ 1/3 更佳）
   - 所有 `[待核验]` 条目集中列在末尾，附检索式

### Phase 3：评审十问（答辩模拟，成文前的门禁）

逐个向用户提出以下 10 问，**一次一问，等用户口头回答**。每问收到回答后给出"过 / 弱 / 不过"判定并说明理由；"不过"的问题必须回改报告对应章节。

**类型分流判据**：专硕在第 4、8 问（边际贡献、管理建议）要求落到"可操作、可落地"；学硕在第 2、4 问（理论机制、边际贡献）要求落到"理论增量、学术贡献"。学硕用专硕口径答第 4 问（只说实践意义、说不出理论贡献）判"弱"或"不过"。

1. 用一句话说出你的研究问题。（说不清 = 最严重的红旗）
2. X 与 Y 的关系为什么成立？理论机制是什么？
3. 数据从哪来？样本多大？凭什么说它有代表性？
4. 同题研究已经不少，你的边际贡献是什么？
5. 你怎么处理因果问题 / 内生性？（实证类必问；案例类改问：凭什么这个案例能回答你的问题）
6. 变量为什么这么测？量表出处和信效度？
7. 如果假设不成立（或案例结论相反），论文还成立吗？
8. 你的结论能给企业什么可操作的建议？谁来做、做什么？
9. 时间和工作量：你确定答辩前写得完吗？依据是什么？
10. 60 秒电梯陈述：现在把整篇论文的逻辑讲一遍。

模拟结束后产出弱点清单，回改 Phase 2 对应小节。

### Phase 4：交付

写入两个文件：

- `thesis/02-开题报告.md`：七大件完整成稿，含技术路线图
- `thesis/02-答辩十问备忘.md`：十问 + 用户回答 + 判定 + 修改记录（答辩前复习用）

交付时附一句风险提示：`[待核验]` 文献必须在开题前核实完毕。

## 风格要求

- 辅导语气：先框架后成文，确认再落笔
- 文风遵守去 AI 味规则：禁空话开头、少用"综上所述/赋能/抓手"、数字具体化
- 与后续衔接：交付时提示"下一步使用 mba-thesis-flow 开始论文写作一条龙"
