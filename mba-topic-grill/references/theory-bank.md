# 理论配对速查库（theory-bank）

选题阶段给候选题配理论视角时使用。原则：**现象可以新，理论必须成熟**——文献综述的骨架锚在理论文献上，热点现象才写得动综述。

## 使用规则（先读）

1. **三步配对**：① 定位现象层次（个体 / 团队 / 组织 / 跨组织）→ ② 在下表按场景找 2-3 个候选理论 → ③ 过"构念可测性"检查：理论的关键构念，用户的数据测得到吗？测不到就换。
2. **理论与分析框架的红线**：PEST、波特五力、SWOT、平衡计分卡、商业模式画布是**分析框架**（组织分析的结构工具），不是理论（解释因果机制的命题体系），不得填入"理论视角"。分析框架放研究设计章节。
3. **主/副理论口径**：实证题主理论 1 个 + 副理论 0-1 个（副理论解释调节/边界），两个理论必须写清分工接口；案例题最多 3 个。多理论拼贴说不清接口 = 两张皮，砍到说清为止。
4. **量表来源**：优先原文献、权威综述、经典教材中的成熟量表；自编量表是最后手段（构念效度是盲审雷区）。

## 场景 1：数字化 / AI 工具 / 信息系统

| 理论 | 核心命题一句话 | 适合解释（MBA 高频场景） | 典型变量组合 | 用滥的坑 |
|---|---|---|---|---|
| 技术接受模型 TAM | 感知有用性、感知易用性决定使用态度与意愿 | 个体层：员工为什么用/不用某系统、AI 工具 | 感知有用性/易用性 → 使用意愿 → 使用行为 | 裸用会被批老旧，建议升级 UTAUT 或做情境化扩展；注明用哪一版 |
| UTAUT / UTAUT2 | 绩效期望、努力期望、社会影响、便利条件共同决定使用意向 | 个体层：不同岗位/代际员工采纳意愿差异 | 四构念 → 行为意向/使用行为，可加性别年龄等调节 | 构念多、量表长，问卷容易超长；调节变量别全塞 |
| 任务-技术匹配 TTF | 技术能力与任务要求匹配时才产生绩效 | "同一个工具不同部门效果不同"、工具落地失败 | 任务特征 × 技术特征 → 匹配 → 利用/绩效 | "匹配"有自己的量表，别拿满意度凑 |
| 信息系统成功模型 D&M | 系统质量/信息质量 → 使用与用户满意 → 净收益 | 评价 ERP/中台/信息化项目成效 | 质量 → 满意/使用 → 净收益 | "净收益"要落到可测指标（效率、差错率），别停在满意度 |
| TOE 框架 | 技术、组织、环境三层因素决定组织层面的技术采纳 | 组织层：企业为什么上/不上某技术、行业对比 | 三层因素 → 采纳决策/采纳程度 | 是组织层框架，别用来解释个体员工行为；与 DOI 二选一 |
| 创新扩散理论 DOI | 相对优势、兼容性、复杂性等属性决定扩散速度 | 一项技术/实践在企业内、行业内推广快慢 | 创新属性 → 采纳速度/采纳率 | 属性清单按对象裁剪，五个属性全测问卷太长 |

## 场景 2：战略 / 组织能力 / 绩效

| 理论 | 核心命题一句话 | 适合解释（MBA 高频场景） | 典型变量组合 | 用滥的坑 |
|---|---|---|---|---|
| 资源基础观 RBV | 有价值、稀缺、难模仿、难替代的资源带来持续竞争优势 | 什么资源（数据、人才、品牌、流程）撑起优势 | 关键资源 → 竞争优势/绩效 | 最高频的"帽子理论"：必须落到具体资源的转化机制，否则就是贴标签 |
| 动态能力理论 | 感知机会、抓住机会、重构资源的能力决定环境剧变下的绩效 | 数字化转型、战略调整、跨界竞争 | 环境动态性 × 动态能力 → 绩效/转型效果 | 别把"企业做了变革"当动态能力，要测感知-抓取-重构三过程 |
| 知识基础观 KBV | 企业的本质是知识整合，整合能力决定竞争优势 | 研发团队、知识密集型组织的效率与创新 | 知识整合/共享机制 → 创新/绩效 | 常与组织学习混用，选一个说清楚 |
| 吸收能力 | 识别、消化、应用外部知识的能力决定创新绩效 | 产学研合作、对标学习、引进技术后的消化 | 外部知识获取 → 吸收能力 → 创新绩效 | 别用"培训次数"当吸收能力；按 Zahra & George 的四维走 |
| 组织双元理论 | 探索与利用活动要平衡，双元性带来长期绩效 | 转型期既要守存量又要创新的两难 | 探索/利用 → 平衡或联合 → 绩效 | 先想清楚测"平衡"还是"联合"，两者量表不同 |
| 高阶理论 | 组织的决策与绩效反映高管团队的认知与特征 | 一把手/高管团队对企业行为的影响 | 高管特征/认知 → 战略选择 → 绩效 | 适合案例题；实证要先确认高管层数据拿得到 |

## 场景 3：治理 / 激励 / 员工行为（个体层，问卷友好）

| 理论 | 核心命题一句话 | 适合解释（MBA 高频场景） | 典型变量组合 | 用滥的坑 |
|---|---|---|---|---|
| 委托代理理论 | 信息不对称 + 利益不一致时，需要激励与监督机制 | 治理、股权激励、承包制、渠道激励 | 激励/监督机制 → 代理成本/努力水平 | 前提是真实存在利益冲突，解释合作关系时会错位 |
| 交易成本理论 | 资产专用性、不确定性、交易频率决定治理形式 | 外包、代工、渠道模式、平台 vs 自营 | 交易属性 → 治理形式/绩效 | 概念抽象，案例题好写，问卷实证难测 |
| 社会交换理论 | 互惠与信任驱动长期关系与额外付出 | 领导-下属、组织支持感、员工回报行为 | 组织支持/领导支持 → 信任/承诺 → 绩效/组织公民行为 | 万金油理论，必须说清交换的"标的物"是什么 |
| 心理契约 | 员工对隐性义务的信念被违背时，态度与行为退缩 | 薪酬改革、组织调整、裁员后的员工反应 | 心理契约违背 → 满意度↓ / 离职意向↑ | "违背感知"有专门量表，别用满意度凑 |
| 组织公平理论 | 分配、程序、互动三维公平感决定态度与行为 | 绩效改革、薪酬方案落地的阻力 | 三维公平感 → 承诺/组织公民行为/离职 | 三维度别混着测；改革类题目天然适配 |
| 资源保存理论 COR | 资源受威胁或损失时，个体产生压力与防御行为 | 数字化工具带来的负荷、加班、职业倦怠 | 要求/资源损失 → 倦怠/退缩；资源获得 → 投入 | 近年高频好用；"资源"要具体化，别悬空 |
| 工作要求-资源模型 JD-R | 工作要求导致耗竭，工作资源激发投入，双路径并行 | 岗位压力、混合办公、一线员工状态 | 要求 → 倦怠 → 结果；资源 → 投入 → 结果 | 双路径别只测一条；调节变量选一个讲透 |

## 场景 4：变革 / 学习 / 创新

| 理论 | 核心命题一句话 | 适合解释（MBA 高频场景） | 典型变量组合 | 用滥的坑 |
|---|---|---|---|---|
| 组织学习理论 | 通过单环/双环学习实现适应与纠偏 | 复盘机制、知识管理、犯错后的组织反应 | 学习机制 → 绩效/创新 | 单双环要分清，别把"组织培训"当组织学习 |
| Lewin 三阶段变革模型 | 解冻-变动-再冻结：打破旧均衡、固化新均衡 | 变革管理案例的标准骨架 | 阶段 × 阻力/驱动 → 变革成败 | 框架性模型，单独当理论视角显单薄，配变革阻力或制度理论 |
| 计划行为理论 TPB | 态度、主观规范、知觉行为控制决定意向，意向决定行为 | 合规行为、新系统使用等行为意愿 | 态度/主观规范/知觉控制 → 意向 → 行为 | 加变量要有理论理由，别无限扩展 |
| 社会认知理论 | 自我效能（对自身能力的信念）驱动行为选择与坚持 | 培训后行为改变、新工具上手、转型信心 | 自我效能 → 意向/行为 | 自我效能有专门量表，别用"自信心"糊 |
| 心理安全感 | 团队内人际安全感决定成员敢不敢发声、试错、报错 | 团队创新、差错报告、扁平化沟通 | 领导行为/氛围 → 心理安全感 → 发声/学习行为 | 标准出处是 Edmondson 量表；别测成"人际信任" |

## 场景 5：外部环境 / 网络 / 关系

| 理论 | 核心命题一句话 | 适合解释（MBA 高频场景） | 典型变量组合 | 用滥的坑 |
|---|---|---|---|---|
| 制度理论 | 组织为获取合法性而趋同（强制/模仿/规范三种同构） | 政策响应、行业模仿潮、ESG 动因 | 制度压力 → 组织响应/合法性 | "大家都做所以我也做"要落到三种压力中的哪一种 |
| 利益相关者理论 | 企业要平衡股东之外的多方诉求 | ESG、社会责任、供应链责任 | 相关者压力 → 决策/绩效 | 涉及方选 2-3 类核心相关者讲透，别贪多 |
| 社会资本理论 | 结构、关系、认知维度的社会资本带来信息与资源优势 | 渠道、供应链协同、产业集群、团队网络 | 社会资本 → 资源获取 → 绩效/创新 | 三个维度按研究对象裁剪，别全测 |
| 强弱关系/网络嵌入 | 弱关系传递新信息，强关系传递信任与深度资源 | 求职、获客、跨部门协作 | 关系强度/嵌入性 → 信息/资源 → 结果 | Granovetter 原命题是求职场景，迁移要说明理由 |
| 信号理论 | 信息不对称下，可观察的信号影响接收方判断 | 品牌、认证、招聘、融资定价 | 信号 → 接收方感知/决策 | 信号要"贵到低成本方模仿不了"才成立，别写成一般宣传 |

## 配对示例

**例 1（个体层问卷）**："AI 工具使用对研发人员工作效率的影响" → 主理论 TTF（任务-技术匹配解释为什么同一工具效果因人而异）+ 副理论 UTAUT（解释使用意愿前因）；量表直接取两理论的成熟量表。

**例 2（组织层案例）**："传统制造企业数字化转型的组织阻力" → Lewin 三阶段（变革过程骨架）+ 制度理论（解释阻力中的合法性考量）；概念模型写成"现象-理论-命题"对应。

**例 3（组织层实证）**："AI 工具应用对研发团队组织能力的影响机制" → 主理论动态能力（感知-抓取-重构对应能力演化）+ 副理论 TOE（解释采纳前因）；调节变量从 TOE 的组织/环境层取。
